# Multiple sessions

Pi Code supports running multiple agent sessions simultaneously.

## Session Management

- **New Session** — Click the `+` button in the chat toolbar, or press `Cmd+N` when the chat is focused
- **Close Session** — Press `Cmd+Shift+W` to close the current session
- **Reopen Session** — Press `Cmd+Shift+T` to reopen the most recently closed session
- **Fork Session** — Create a copy of the current session to explore an alternative approach

Each session maintains its own conversation state and model selection — perfect for working on multiple tasks in parallel.

> **Tip**: Use `/resume` within a session to browse and restore past conversations from disk.
