# Open Pi Code

You can open Pi Code in several ways:

- **Activity bar** — Click the Pi Code icon in the left sidebar
- **Keyboard** — Press `Cmd+Shift+Escape` (`Ctrl+Shift+Escape` on Windows/Linux)
- **Command Palette** — Press `Cmd+Shift+P` and search for "Pi Code: Show Pi Chat"

## Quick Focus

Press `Cmd+Escape` (`Ctrl+Escape`) to toggle focus between the chat input and your editor.

> **Tip**: Select code in your editor before opening Pi Code — Pi will see the selection context.
