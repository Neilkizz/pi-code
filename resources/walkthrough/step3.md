# Chat with Pi

Type a message in the chat input and press Enter to send. Pi will respond with text, code, and actions.

## @-mentions

Type `@` in the chat input to reference files, folders, or symbols in your workspace for context.

## Slash Commands

Type `/` to see the available slash commands:

- `/login` — Authenticate with Pi
- `/compact` — Compact the conversation context
- `/copy` — Copy the last response
- `/help` — Show available commands

## Model & Thinking

Use the toolbar buttons to:

- **Cycle models** — Switch between available LLM providers
- **Adjust thinking level** — Control how much reasoning the agent shows
