# Your AI coding partner

Pi Code brings the [Pi coding agent](https://pi.dev) directly into VS Code as a native chat panel. It can:

- Write, edit, and refactor code
- Run bash commands and see output
- Read and analyze your project files
- Manage multiple agent sessions concurrently
- Review changes with inline diff before accepting

## Getting Started

Click the Pi Code icon in the activity bar (left sidebar), or press `Cmd+Shift+Escape` to open Pi Code.

> **Prerequisite**: The `pi` CLI must be installed. See [pi.dev](https://pi.dev) for installation instructions.
