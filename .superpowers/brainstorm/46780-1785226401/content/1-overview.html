核心布局与功能架构对比 (Architecture & UI Comparison)
UI 区域 / 模块 Anthropic 官方 Claude Code 插件 当前 Pi Code 实现 一比一整改方案
1. 顶部历史与会话栏 包含 "Past conversations" / 历史会话切换 Tab、可视化会话列表与新建按钮。 使用传统的工具栏 (Pi • Model • Thinking 按钮)，略显繁琐。 移除繁重的旧工具栏，重构为顶部极简会话 Header + 可切换的 "Past Conversations" 历史记录面板。
2. 选中代码与上下文指示 选中文本时自动显示 "XX lines selected"，按 Option+K / Alt+K 插入 `@file#L10-L25` 带有行号的精确引用。 仅支持粗粒度 @文件 匹配，无代码选择行数实时指示器及图标。 在输入框顶部新增选中文本与附件动态 Badge 行，支持精确行号指示器 (`@file#L10-L25`)。
3. 底部 Prompt 交互卡片 陶土橘边框卡片，左下 `+` (Actions), `[/]` (Slash), 右下 `⚡ Auto` (Modes) 与 `↑` (Submit)。 基本外观有了，但在弹窗尺寸、字体、阴影、滑块和高亮项目上仍存在微小视觉偏离。 精细微调 CSS 尺寸、圆角 (12px)、阴影、弹窗定位与高亮颜色 (#3e432d 橄榄绿 / #ba68c8 紫色滑块点)。
4. 计划模式 (Plan Mode) 交互 切换到 Plan 模式时，自动生成完整计划并在编辑器中打开大纲/Markdown 进行确认。 在聊天框内纯文本输出，缺乏单独的计划文档与确认按钮。 实现 Visual Plan UI：Agent 产生 Plan 时在 UI 中渲染结构化 Plan 卡片并提供 "Accept Plan" / "Tell Claude what to do instead" 交互按钮。
